# CoreSpec Hardware Store (Mobile-First E-Commerce PWA)

Mobile-first Progressive Web Application (PWA) built with React (Vite) for **ITE101 – Mobile Application Development**.

## Tech Stack
- **Frontend:** React 19, Vite, React Router DOM, `vite-plugin-pwa` (Workbox)
- **Backend API:** Node.js + Express REST API (`/api/v1`)
- **Database & Auth:** Supabase PostgreSQL + JWT Role-Based Access Control
- **Payment Gateway:** Maya Sandbox Hosted Checkout
- **AI Product Discovery:** Grounded server-side Gemini API integration
